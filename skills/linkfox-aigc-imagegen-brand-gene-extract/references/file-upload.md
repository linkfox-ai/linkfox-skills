# 文件上传

将本地商品图片上传至 LinkFox 提供凭证的阿里云 OSS，获得下游视觉推理可访问的公开 HTTPS URL；已有可公开访问的 HTTP(S) URL 直接复用。

## 执行

1. 上传前明确告知文件将获得公开可访问 URL；只有用户确认内容可以公开后才执行。“上传这个文件”本身不等于确认可以公开。禁止上传敏感或私密内容。
2. 依次整理待上传的本地路径，保留输入顺序。读取 [接口定义](api.md#接口获取-oss-临时上传凭证) 中的凭证规则、认证兼容、依赖与服务端限制。
3. 从本技能根目录运行 `python scripts/upload_files.py <文件> [<文件> ...]`；脚本自行通过公共调用器获取凭证，再经 OSS SDK 上传，不需要安装额外上传 skill，也无需另行导出凭证。

```powershell
# $paths 为待上传路径数组；先切到本技能根目录。
python scripts/upload_files.py @paths
```

4. 脚本按原序输出 JSON 数组和每个成功文件的保存/上传提示。只使用成功项的 url；任一失败时说明 message 并停止后续品牌提取。不重复上传已成功项，完整结果与退出码定义见 [上传输出](api.md#oss-上传器本地输出非-linkfox-接口)。

## 公开 URL 与会话登记

成功 URL 登记到会话 `_meta.json` 的 deliverables，可直接传入 textgen。源文件保持原样；不输出 STS 凭证，凭证响应在公共落盘前脱敏。全部字段、类型、文件限制和错误规则集中维护在 [接口定义](api.md)，品牌基因的结构与最终结果落盘另见 [品牌基因约定](brand-gene.md)。
