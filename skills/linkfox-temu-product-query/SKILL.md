# Temu 商品查询

## 适用范围

### 适用

按多维条件查找 Temu 商品，比较候选商品的价格、销量和买家评价指标。
用户希望在 Temu（拼多多跨境）搜商品、筛选全托管或半托管商品、查找爆款时，使用本技能。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 找一些厨房类 Temu 商品 | 按关键词或已知类目筛选商品。 |
| 看这个商品 ID 或店铺 ID 的商品 | 根据用户提供的标识查询。 |
| 找价格适中、周销量较高的商品 | 按价格和销量筛选并排序。 |
| 看某地区的半托管商品 | 按托管模式和半托管地区筛选。 |
| 找最近上架、评分较高的商品 | 按上架时间和评分筛选。 |

## 前置条件

根据用户目标确定检索词或筛选条件；需要按类目查询但只有类目名称时，先从 Temu 品类检索数据源取得对应编号，区分前台与后台类目。参数定义见 [references/api.md](references/api.md)。

## 查询流程

1. 明确用户要查的商品范围和筛选目标，按接口定义准备检索词、类目及其他条件。
2. 告知动态算力消耗，由用户决定是否继续；在用户授权的范围内发起查询，优先复用相同参数的已有结果。
3. 按接口参考判断响应，展示本页结果及匹配总数；无数据或报错时说明原因，继续查询遵守成本约束。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/temu_product_query.py '<JSON 参数>' [--inline]`。
- **成本约束**：本页每返回 1 个产品消耗 1.8 算力。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改筛选条件连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-temu-product-query-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应 JSON 格式化后的 UTF-8 大小不超过 8000 字节：保存后，将完整 JSON 打印到标准输出。
- 响应 JSON 格式化后的 UTF-8 大小超过 8000 字节：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

消耗算力 = 本页返回产品数量 × 1.8。翻到下一页是一次新请求，按下一页返回条数重新计算。

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **区分类目与托管模式**：前台类目和后台类目属于不同筛选维度；全托管与半托管也应分别解读，半托管地区用于说明候选商品的覆盖范围。
- **展示查询口径**：用表格列出实际返回的商品编号、中英文名称、价格、总/周/日/月销量、评分、评论数、上架时间、店铺和托管模式；缺失字段不补造。
- **区分样本与总体**：明确本页返回条数与符合条件的商品总数；摘要中的样本不能代替整页结果，需要更多字段时从已保存文件提取。
- **说明排序与标签**：结合本次查询条件解释列表顺序；商品标签和自定义标签分开展示，不将标签推断成未经证实的经营结论。

## 使用示例

### 按关键词查找商品

用户：帮我看看 Temu 上有哪些厨房用品。

确定关键词和展示范围，说明预计消耗后查询，列出商品价格、销量与评分，并标注本页与匹配总数。

### 筛选半托管候选商品

用户：找某地区近期上架、周销量较高的半托管商品。

明确地区、时间和销量范围，依照接口参考准备成对区间与排序，展示实际返回的商品及托管地区；继续翻页前说明额外消耗。
