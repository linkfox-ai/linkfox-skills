# linkfox-shopee-store-video

> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee 店铺 Video

Shopee Open Platform **Video 模块**（15 个 API）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发（`path` 须 `api/v2/video/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。


## 官方参考

Video 模块索引：[v2.video.get_cover_list](https://open.shopee.com/documents/v2/v2.video.get_cover_list?module=129&type=1)

## Prerequisites（必须先读）

先用 `shopee/authorizedStores` 按 `shopId`/`merchantId + appType` 确认授权；缺失时按授权 reference 获取新授权 URL。

---

## Core Concepts

- **转发链路**：`developerProxy`（`shopId`/`merchantId` 选店，服务端注入 token）→ 紫鸟 `shopee-proxy` → Shopee API
- **视频管理**：`get_cover_list` → `post_video` → `get_video_list` / `edit_video_info`
- **效果分析**：`get_overview_performance`、`get_video_detail_performance` 等
- **官方拼写**：`get_prodcut_performance_list`（product 为 prodcut）
- **直播 Livestream**（module 不同）→ `linkfox-shopee-store-livestream`



## Usage Scenarios

### 1. 发布视频
1. `get_cover_list` 选封面
2. `post_video` 传完整 `body`
3. `get_video_list` 确认发布

### 2. 查视频效果
1. `get_video_list` 获取 `video_id`
2. `get_video_detail_performance` 查单视频效果
3. `get_overview_performance` 查整体概览

## 调用原则

- 先看 **`developerProxy.httpStatus`**，再读 `*Response` 字段
- GET：业务参数放 JSON 顶层
- POST：复杂接口传 `body`
- 每个 operation 文档 含 **官方文档 URL**（`module=129`）

## Not Applicable

- 店铺授权 → `linkfox-shopee-store-auth`
- 商品 listing → `linkfox-shopee-store-product`
- 直播 Livestream → `linkfox-shopee-store-livestream`
- 视频文件上传（MediaSpace）→ `linkfox-shopee-store-media-space`
- 视频文件上传（Media）→ `linkfox-shopee-store-media`

## 积分消耗规则

不消耗积分。
