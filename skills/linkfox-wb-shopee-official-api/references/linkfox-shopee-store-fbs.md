# linkfox-shopee-store-fbs

> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee FBS 巴西仓储

Shopee Open Platform **FBS 模块**（4 个 API，均为 GET，面向巴西 BR）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发（`path` 须 `api/v2/fbs/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。

## Prerequisites

2. 通用 SBS 仓储 → `linkfox-shopee-store-sbs`；物流 → `linkfox-shopee-store-logistics`。



## Usage Scenarios

### 1. 查巴西 FBS 店铺状态
1. `query_br_shop_enrollment_status` 入驻状态
2. `query_br_shop_block_status` 店铺封禁
3. `query_br_sku_block_status` SKU 封禁

### 2. 排查发票问题
`query_br_shop_invoice_error` 查发票错误

## Not Applicable

- 店铺授权 → `linkfox-shopee-store-auth`
- SBS 通用仓储库存 → `linkfox-shopee-store-sbs`
- 物流发货 → `linkfox-shopee-store-logistics`
- 商品 listing → `linkfox-shopee-store-product`

## 积分消耗规则

不消耗积分。

## Operation: query_br_shop_block_status

| 项 | 值 |
|----|-----|
| operation | `query_br_shop_block_status` |
| Method / path | GET `api/v2/fbs/query_br_shop_block_status` |
| 官方文档 | [query_br_shop_block_status](https://open.shopee.com/documents/v2/v2.fbs.query_br_shop_block_status?module=126&type=1) |
| 用途 | Brazil FBS shop block status |

经 LinkFox MCP 的 `proxy_call`（`toolName=shopee/developerProxy`）转发；依赖 **`linkfox-shopee-store-auth`** 选店（通常传 `shopId` 或 `merchantId`）。

---

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shopId` | string | 与 `merchantId` 二选一 | 店铺 ID（推荐；Public 等无店铺接口可省略） |
| `merchantId` | string | 与 `shopId` 二选一 | 商户 ID |

- Method：**GET**
- GET：业务字段放 JSON **顶层**，调用方编码进 `queryString`（不含 `?`）
- `shopId` / `merchantId` / `skipDepCheck` 等为网关选店保留字段，不会进 Shopee query/body
- Registry notes：Brazil FBS shop block status

---
