# linkfox-shopee-store-public

> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee Public 公共模块

Shopee Open Platform **Public 模块**（6 个 API）。**依赖 `linkfox-shopee-store-auth`** 作为同系列前置；部分接口为 Partner 级或 OAuth 级，经 `proxy_call`（`toolName=shopee/developerProxy`） 转发（`path` 须 `api/v2/public/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。


## 官方参考

Public 模块索引：[v2.public.get_shops_by_partner](https://open.shopee.com/documents/v2/v2.public.get_shops_by_partner?module=104&type=1)

## Prerequisites

2. **日常授权 / 已授权店铺 / 读 token** → 优先 `linkfox-shopee-store-auth`（`authorize_url` / `authorized_stores` / `store_tokens`）。



## Usage Scenarios

### 1. 查 Partner 下已授权店铺
`get_shops_by_partner` 或 `get_merchants_by_partner`

### 2. OAuth Token 交换（底层开放接口）
`get_access_token` / `refresh_access_token` 传完整 POST `body`

### 3. IP 白名单配置
`get_shopee_ip_ranges` 获取 Shopee 开放平台 IP 段

## Not Applicable

- 用户侧授权流程 → `linkfox-shopee-store-auth`
- 店铺业务 API（订单/商品/物流等）→ 对应业务 skill
- Push 回调配置 → `linkfox-shopee-store-push`

## 积分消耗规则

不消耗积分。

## Operation: get_access_token

| 项 | 值 |
|----|-----|
| operation | `get_access_token` |
| Method / path | POST `api/v2/public/get_access_token` |
| 官方文档 | [get_access_token](https://open.shopee.com/documents/v2/v2.public.get_access_token?module=104&type=1) |
| 用途 | Exchange auth code for access token; pass full body |

经 `proxy_call`（`toolName=shopee/developerProxy`） 转发。Public 多为 Partner / OAuth 级接口，**通常无需** `shopId`/`merchantId`；日常授权优先走 `linkfox-shopee-store-auth`。

---

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shopId` | string | 否 | Public 接口通常可省略 |
| `merchantId` | string | 否 | Public 接口通常可省略 |

- Method：**POST**
- POST：传 `body` / `requestBody`，或把 `body_fields` 列在 JSON 顶层
- `shopId` / `merchantId` / `skipDepCheck` 等为网关选店保留字段，不会进 Shopee query/body
- Registry notes：Exchange auth code for access token; pass full body

---

- MCP server：`LinkFox`
- 唯一工具：`proxy_call`
- `toolName`：`shopee/developerProxy`（精确匹配且区分大小写）
