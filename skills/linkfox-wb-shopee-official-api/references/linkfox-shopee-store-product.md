# linkfox-shopee-store-product

> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee 店铺 Product

Shopee Open Platform **Product 模块**（57 个 API）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发（`path` 须 `api/v2/product/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。

## Core Concepts

- **转发链路**：`developerProxy`（`shopId`/`merchantId` 选店，服务端注入 token）→ 紫鸟 `shopee-proxy` → Shopee API
- **上架流程**：`get_category` → `get_attribute_tree` → `add_item`（复杂 body 建议传 `body` 字段）
- **日常运营**：`get_item_list` / `get_item_base_info` 查商品；`update_price` / `update_stock` 改价改库存；`unlist_item` 上下架
- **SKU**：`init_tier_variation` / `get_model_list` / `add_model` 等
- **选品数据**（非店铺 listing）→ `linkfox-youying-shopee-product-search`（不依赖 auth）



## Usage Scenarios

### 1. 查类目并上架
1. `get_category` 获取类目树
2. `get_attribute_tree` 传 `category_id` 获取必填属性
3. `add_item` 传完整 `body`（含 category_id、item_name、price、image、attribute_list 等）

### 2. 查商品与改库存
1. `get_item_list`：`offset`、`page_size`、`item_status`
2. `get_item_base_info`：`item_id_list`
3. `update_stock` / `update_price`：POST `body`

### 3. 上下架与推广
- `unlist_item`：批量上下架
- `boost_item`：置顶（最多 5 个）

## 调用原则

- 先看 **`developerProxy.httpStatus`**，再读 `*Response` 字段
- GET：业务参数放 JSON 顶层（调用方编码为 queryString）
- POST：复杂接口传 `body`；简单接口可传顶层 body 字段或 `body`
- 每个 operation 文档 含 **官方文档 URL**（`module=89`）

## Operation: add_item

| 项 | 值 |
|----|-----|
| operation | `add_item` |
| Method / path | POST `api/v2/product/add_item` |
| 官方文档 | [add_item](https://open.shopee.com/documents/v2/v2.product.add_item?module=89&type=1) |
| 用途 | Complex body — pass body with category_id, item_name, price, etc. |

经 LinkFox MCP 的 `proxy_call`（`toolName=shopee/developerProxy`）转发；依赖 **`linkfox-shopee-store-auth`** 选店（通常传 `shopId` 或 `merchantId`）。

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shopId` | string | 与 `merchantId` 二选一 | 店铺 ID（推荐；Public 等无店铺接口可省略） |
| `merchantId` | string | 与 `shopId` 二选一 | 商户 ID |

- Method：**POST**
- POST：传 `body` / `requestBody`，或把 `body_fields` 列在 JSON 顶层
- `shopId` / `merchantId` / `skipDepCheck` 等为网关选店保留字段，不会进 Shopee query/body
- Registry notes：Complex body — pass body with category_id, item_name, price, etc.
