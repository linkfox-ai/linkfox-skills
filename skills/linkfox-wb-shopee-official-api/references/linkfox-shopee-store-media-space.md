# linkfox-shopee-store-media-space

> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee 媒体 MediaSpace

Shopee Open Platform **MediaSpace 模块**（6 个 API）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发（`path` 须 `api/v2/media_space/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。


## 官方参考

MediaSpace 模块索引：[v2.media_space.init_video_upload](https://open.shopee.com/documents/v2/v2.media_space.init_video_upload?module=91&type=1)

## Prerequisites（必须先读）

先用 `shopee/authorizedStores` 按 `shopId`/`merchantId + appType` 确认授权；缺失时按授权 reference 获取新授权 URL。

---

## Core Concepts

- **转发链路**：`developerProxy`（`shopId`/`merchantId` 选店，服务端注入 token）→ 紫鸟 `shopee-proxy` → Shopee API
- **图片上传**：`upload_image` → 返回 Shopee 图片 URL（供 `add_item` 等使用）
- **视频分片上传**：`init_video_upload` → `upload_video_part`(×N) → `complete_video_upload` → `get_video_upload_result`
- **视频发布/管理** → `linkfox-shopee-store-video`（Video 模块，非上传）
- **商品 listing** 使用图片 URL → `linkfox-shopee-store-product`



## Usage Scenarios

### 1. 上传商品图片
`upload_image` 传 `body`（按官方 spec），获取 `image_url` 用于 `add_item`

### 2. 分片上传视频
1. `init_video_upload`
2. `upload_video_part`（循环各分片）
3. `complete_video_upload`
4. `get_video_upload_result`

## 调用原则

- 先看 **`developerProxy.httpStatus`**，再读 `*Response` 字段
- POST 上传接口传 `body`；大文件/二进制可能需网关支持 multipart
- 每个 operation 文档 含 **官方文档 URL**（`module=91`）

## Not Applicable

- 店铺授权 → `linkfox-shopee-store-auth`
- Media 模块（`api/v2/media/...`）→ `linkfox-shopee-store-media`
- 视频发布/效果 → `linkfox-shopee-store-video`
- 商品 listing → `linkfox-shopee-store-product`

## 积分消耗规则

不消耗积分。
