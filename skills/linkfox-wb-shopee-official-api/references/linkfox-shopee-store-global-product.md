## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |

| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee 全球商品 GlobalProduct

Shopee Open Platform **GlobalProduct 模块**（34 个 API）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发（`path` 须 `api/v2/global_product/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。


## 官方参考

GlobalProduct 模块索引：[v2.global_product.get_category](https://open.shopee.com/documents/v2/v2.global_product.get_category?module=90&type=1)

## Prerequisites（必须先读）

先用 `shopee/authorizedStores` 按 `shopId`/`merchantId + appType` 确认授权；缺失时按授权 reference 获取新授权 URL。

## Core Concepts

- **转发链路**：`developerProxy`（`shopId`/`merchantId` 选店，服务端注入 token）→ 紫鸟 `shopee-proxy` → Shopee API
- **Product vs GlobalProduct**：`linkfox-shopee-store-product` 管单店 listing；本 skill 管**跨境全球商品**及发布到各站点
- **典型流程**：`get_category` → `get_attribute_tree` → `add_global_item` → `create_publish_task` → `get_publish_task_result`
- **SKU**：`init_tier_variation` / `get_global_model_list` / `add_global_model` 等
- **本地店商品**（非全球）→ `linkfox-shopee-store-product`



## Usage Scenarios

### 1. 创建全球商品并发布
1. `get_category` + `get_attribute_tree`（`merchantId`）
2. `add_global_item` 传完整 `body`
3. `create_publish_task` 发布到目标站点
4. `get_publish_task_result` 查发布结果

### 2. 查全球商品与改库存
1. `get_global_item_list`：`offset`、`page_size`
2. `get_global_item_info`：`global_item_id_list`
3. `update_stock` / `update_price`：POST `body`

## 调用原则

- 先看 **`developerProxy.httpStatus`**，再读 `*Response` 字段
- GET：业务参数放 JSON 顶层（调用方编码为 queryString）
- POST：复杂接口传 `body`；简单接口可传顶层 body 字段
- 每个 operation 文档 含 **官方文档 URL**（`module=90`）

## Not Applicable

- 店铺授权 → `linkfox-shopee-store-auth`
- 商户信息 → `linkfox-shopee-store-merchant`
- 单店 listing → `linkfox-shopee-store-product`
- 订单 → `linkfox-shopee-store-orders`
- 店铺信息 → `linkfox-shopee-store-shop`
- 图片/视频上传 → MediaSpace 模块

## 积分消耗规则

不消耗积分。
