# linkfox-shopee-store-media

> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee 媒体 Media

Shopee Open Platform **Media 模块**（6 个 API，**`api/v2/media/...`**，module=130）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。

Media 模块索引：[v2.media.upload_image](https://open.shopee.com/documents/v2/v2.media.upload_image?module=130&type=1)

|-------|-----------|--------|
| **本 skill** `linkfox-shopee-store-media` | `api/v2/media/...` | 130 |
| `linkfox-shopee-store-media-space` | `api/v2/media_space/...` | 91 |

接口名称相同（`upload_image`、`init_video_upload` 等），但 **path 前缀不同**。请按 LinkFox 网关白名单选择对应 skill。

2. **不要**在本 skill 内实现授权/令牌逻辑。



## Usage Scenarios

### 上传图片
`upload_image` → 获取 Shopee 图片 URL → 用于 `linkfox-shopee-store-product` 的 `add_item`

### 分片上传视频
`init_video_upload` → `upload_video_part`(×N) → `complete_video_upload` → `get_video_upload_result`

## Not Applicable

- 店铺授权 → `linkfox-shopee-store-auth`
- MediaSpace（`api/v2/media_space/...`）→ `linkfox-shopee-store-media-space`
- 视频发布/效果 → `linkfox-shopee-store-video`

## 积分消耗规则

不消耗积分。

## Operation: cancel_video_upload

| 项 | 值 |
|----|-----|
| operation | `cancel_video_upload` |
| Method / path | POST `api/v2/media/cancel_video_upload` |
| 官方文档 | [cancel_video_upload](https://open.shopee.com/documents/v2/v2.media.cancel_video_upload?module=130&type=1) |
| 用途 | Cancel in-progress video upload |

经 LinkFox MCP 的 `proxy_call`（`toolName=shopee/developerProxy`）转发；依赖 **`linkfox-shopee-store-auth`** 选店（通常传 `shopId` 或 `merchantId`）。

---

### 请求参数

| 字段 | 类型 | 必填 | 说明 |

| `merchantId` | string | 与 `shopId` 二选一 | 商户 ID |

- Method：**POST**
- POST：传 `body` / `requestBody`，或把 `body_fields` 列在 JSON 顶层
- `shopId` / `merchantId` / `skipDepCheck` 等为网关选店保留字段，不会进 Shopee query/body
- Registry notes：Cancel in-progress video upload
