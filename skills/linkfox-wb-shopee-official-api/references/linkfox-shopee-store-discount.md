# linkfox-shopee-store-discount

> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee 店铺 Discount

Shopee Open Platform **Discount 模块**（12 个 API）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发（`path` 须 `api/v2/discount/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。


## 官方参考

Discount 模块索引：[v2.discount.add_discount](https://open.shopee.com/documents/v2/v2.discount.add_discount?module=99&type=1)

## Prerequisites

2. Bundle Deal / Voucher 等其它促销模块 → 非本 skill。



## Usage Scenarios

### 1. 创建折扣活动
1. `add_discount` 传完整 `body`（名称、时间、折扣类型等）
2. `add_discount_item` 添加参与商品
3. `get_discount_list` 确认活动状态

### 2. 管理现有活动
- `get_discount` 查详情
- `update_discount` / `update_discount_item` 修改
- `end_discount` 提前结束

## Not Applicable

- 店铺授权 → `linkfox-shopee-store-auth`
- Bundle Deal / Voucher / Add-On Deal / Shop Flash Sale / Follow Prize → 其它促销模块 skill（Bundle Deal → `linkfox-shopee-store-bundle-deal`；Add-On Deal → `linkfox-shopee-store-add-on-deal`；Voucher → `linkfox-shopee-store-voucher`；Shop Flash Sale → `linkfox-shopee-store-shop-flash-sale`；Follow Prize → `linkfox-shopee-store-follow-prize`）
- 商品 listing → `linkfox-shopee-store-product`

## 积分消耗规则

不消耗积分。

## Operation: add_discount

| 项 | 值 |
|----|-----|
| operation | `add_discount` |
| Method / path | POST `api/v2/discount/add_discount` |
| 官方文档 | [add_discount](https://open.shopee.com/documents/v2/v2.discount.add_discount?module=99&type=1) |
| 用途 | Create discount promotion; pass full body |

经 LinkFox MCP 的 `proxy_call`（`toolName=shopee/developerProxy`）转发；依赖 **`linkfox-shopee-store-auth`** 选店（通常传 `shopId` 或 `merchantId`）。

---

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shopId` | string | 与 `merchantId` 二选一 | 店铺 ID（推荐；Public 等无店铺接口可省略） |
| `merchantId` | string | 与 `shopId` 二选一 | 商户 ID |

- Method：**POST**
- POST：传 `body` / `requestBody`，或把 `body_fields` 列在 JSON 顶层
- `shopId` / `merchantId` / `skipDepCheck` 等为网关选店保留字段，不会进 Shopee query/body
- Registry notes：Create discount promotion; pass full body
