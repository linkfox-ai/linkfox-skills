> 本文件归档该业务能力的执行说明、接口参数、响应字段、错误处理与认证规则。通过 LinkFox MCP 执行。

## MCP 传输契约

本 reference 的所有业务 operation 共享以下传输层；各 operation 的业务 `path`、`method`、请求参数、响应字段、枚举、区域限制和状态机仍以各节为准。

| 项 | 值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `shopee/developerProxy` |
| `arguments` | 直接使用对应 operation 的 developerProxy 请求对象 |

WorkBuddy 自动注入 Authorization；MCP 配置和 `arguments` 中禁止放置 `headers`、手工凭证、token、JWT、手机号或其他凭证。MCP/`proxy_call` 缺失时停止，不得用 curl、`urllib`、`requests`、`httpx` 或本地脚本静默回退。


# Shopee 商户 Merchant

Shopee Open Platform **Merchant 模块**（6 个 API）。**依赖 `linkfox-shopee-store-auth`** 选店；经 `proxy_call`（`toolName=shopee/developerProxy`） 传入 `shopId`（或 `merchantId`），由服务端解析 token 转发（`path` 须 `api/v2/merchant/...`）。

## 调用方式

仅使用 `LinkFox.proxy_call`。所有 operation 的精确 `toolName` 均为 `shopee/developerProxy`；请求形状、解析顺序、去重和错误分层见上方 MCP 传输契约及各 operation 的 MCP 调用节。


## 认证和积分问题

按 `onboarding.md` 分层处理 MCP 401、下游 401/402、403 和其他业务错误。WorkBuddy 自动注入 Authorization；不得收集或传入 Key/token。


## 官方参考

Merchant 模块索引：[v2.merchant.get_merchant_info](https://open.shopee.com/documents/v2/v2.merchant.get_merchant_info?module=93&type=1)

## Prerequisites（必须先读）

先用 `shopee/authorizedStores` 按 `shopId`/`merchantId + appType` 确认授权；缺失时按授权 reference 获取新授权 URL。

---

## Core Concepts

- **转发链路**：`developerProxy`（`shopId`/`merchantId` 选店，服务端注入 token）→ 紫鸟 `shopee-proxy` → Shopee API
- **商户 vs 店铺**：本 skill 查商户信息及下属店铺；单店资料见 `linkfox-shopee-store-shop`
- **全球商品**：商户下全球 listing 见 `linkfox-shopee-store-global-product`
- **典型用法**：`get_merchant_info` 确认 region/currency → `get_shop_list_by_merchant` 列出授权店铺



## Usage Scenarios

### 1. 查商户信息与下属店铺
1. auth skill 定位 `merchantId`
2. `get_merchant_info`：name、region、currency、授权过期
3. `get_shop_list_by_merchant`：`page_no=1`、`page_size=100`

### 2. 仓库与预付账户
- `get_merchant_warehouse_list` / `get_merchant_warehouse_location_list`
- `get_warehouse_eligible_shop_list`
- `get_merchant_prepaid_account_list`

## 调用原则

- 先看 **`developerProxy.httpStatus`**，再读 `*Response` 字段
- GET：业务参数放 JSON 顶层（调用方编码为 queryString）
- 每个 operation 文档 含 **官方文档 URL**（`module=93`）

## Not Applicable

- 店铺授权 → `linkfox-shopee-store-auth`
- 单店信息 → `linkfox-shopee-store-shop`
- 全球商品 → `linkfox-shopee-store-global-product`
- 单店 listing → `linkfox-shopee-store-product`
- 订单 → `linkfox-shopee-store-orders`
- Public 模块（`get_merchants_by_partner` 等）→ 非本 skill

## 积分消耗规则

不消耗积分。

## Operation: get_merchant_info

| 项 | 值 |
|----|-----|
| operation | `get_merchant_info` |
| Method / path | GET `api/v2/merchant/get_merchant_info` |
| 官方文档 | [get_merchant_info](https://open.shopee.com/documents/v2/v2.merchant.get_merchant_info?module=93&type=1) |
| 用途 | Merchant name, region, currency, auth/expire time |

经 LinkFox MCP 的 `proxy_call`（`toolName=shopee/developerProxy`）转发；依赖 **`linkfox-shopee-store-auth`** 选店（通常传 `shopId` 或 `merchantId`）。

---

### 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shopId` | string | 与 `merchantId` 二选一 | 店铺 ID（推荐；Public 等无店铺接口可省略） |
| `merchantId` | string | 与 `shopId` 二选一 | 商户 ID |

- Method：**GET**
- GET：业务字段放 JSON **顶层**，调用方编码进 `queryString`（不含 `?`）
- `shopId` / `merchantId` / `skipDepCheck` 等为网关选店保留字段，不会进 Shopee query/body
- Registry notes：Merchant name, region, currency, auth/expire time

---
