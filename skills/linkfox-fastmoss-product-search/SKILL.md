# FastMoss TikTok 商品搜索

## 适用范围

### 适用

搜索和筛选 TikTok Shop 商品数据，比较销量、价格、佣金和达人推广表现。
用户希望了解“TikTok 上什么卖得好”或寻找候选商品，且需要基于商品数据检索时，使用本技能。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 找 TikTok 热销商品 | 关键词搜索并按销量排序。 |
| 找佣金较高的商品 | 按佣金率范围筛选和排序。 |
| 美国站什么卖得好 | 指定市场比较商品销量。 |
| 看跨境店铺的商品 | 按店铺类型筛选。 |
| 哪些商品有很多达人带货 | 按带货达人数筛选和排序。 |
| 找全托管商品 | 筛选 TikTok 全托管商品。 |
| 查东南亚市场的商品 | 指定对应市场搜索。 |
| 找最近上架的热销商品 | 结合热销与新上架条件。 |
| 查 FastMoss 商品数据 | 按目标商品和市场组织检索。 |

### 边界

达人粉丝数或互动率、特定视频播放量或点赞分享、店铺整体经营分析、广告管理、内容策略与视频创作、达人联络、商品刊登创建或优化建议、物流履约分析，以及 Amazon、Shopee 等其他平台商品数据均不在本技能范围。

## 前置条件

所有请求字段均可选；建议至少提供关键词或类目，以取得有意义的结果。根据用户已给出的目标市场及比较重点组织查询，未指定市场不构成必填缺失；筛选条件、市场支持范围与使用限制见 `references/api.md`。

## 查询流程

1. 根据用户的检索目标，以及已指定的市场、销量、GMV、佣金或达人推广等关注点整理筛选和排序条件；按 `references/api.md` 核对参数约定，不将可选字段设为调用前置门槛。
2. 检查是否已有相同参数的结果，优先复用会话数据或脚本缓存；需要请求时执行一次搜索。
3. 先看响应摘要，按需从完整响应文件提取商品字段，用表格展示本次结果和返回范围。
4. 失败时根据实际响应解释原因，提出可调整的条件；空结果或失败后不自动变更条件连续检索，后续请求遵守成本约束。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/fastmoss_product_search.py '<JSON 参数>' [--inline]`。
- **成本约束**：本工具会消耗算力。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改邮编连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-fastmoss-product-search-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

11 算力 / 次

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **展示数据**：用表格展示商品名称、价格、累计销量、近 7 天销量、GMV、评分、佣金率和带货达人数，不附加主观经营建议。
- **区分统计周期**：FastMoss 追踪不同市场的商品表现。销量可包含 1 天、7 天、28 天、90 天和累计值；GMV 表示成交金额，按实际返回的周期分别展示，不补造未返回的周期数据。
- **佣金百分比**：将响应中的佣金小数转换为百分比展示，例如 0.10 显示为 10%。
- **店铺分类**：明确展示本地与跨境标识，并直接展示全托管和包邮文本；字段含义见接口定义。
- **币种与趋势**：价格和 GMV 使用响应的 `currency` 标明币种；直接使用 `salesTrendFlagText` 作为趋势标签，`freeShippingText`、`isSShopText` 使用原始可读文本。
- **保留可核验信息**：按需补充商品编号、类目、店铺、上架时间、SKU 数、评论数、视频数、直播数、商品链接和图片；只展示实际返回的数据。

## 使用示例

### 按累计销量查找手机壳

```json
{"keyword": "phone case", "region": "US", "orderField": "total_units_sold", "pageSize": 10}
```

### 查找高佣金美妆商品

```json
{"keyword": "beauty", "region": "US", "commissionRateRange": {"min": 0.10}, "orderField": "commission_rate"}
```

### 查看跨境店铺的热门小工具

```json
{"keyword": "gadget", "region": "US", "shopType": 2, "orderField": "day7_units_sold"}
```

### 查找达人带货较多的护肤商品

```json
{"keyword": "skincare", "region": "US", "creatorCountRange": {"min": 50}, "orderField": "creator_count"}
```

### 查找英国站新上架的热销时尚商品

```json
{"keyword": "fashion", "region": "GB", "isTopSelling": true, "isNewListed": true, "orderField": "day7_gmv"}
```
