# Etsy 类目检索

## 适用范围

### 适用

在已同步的 Etsy 类目库中查找类目标识及父类目关系。
用户希望根据名称、已知类目编号或父类目线索确定用于后续筛选的类目时，使用本技能。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 找一下 Etsy 的 jewelry 类目 | 根据名称查找匹配类目。 |
| 核对这个 Etsy category id 对应什么类目 | 根据已知编号查询类目名称与层级。 |
| 找到这个父类目相关的 Etsy 品类 | 根据父类目线索查询匹配记录。 |

## 前置条件

**确认类目库已同步**：本技能查询已有类目库。同步来源及数据范围见 [接口说明](references/api.md)；本技能不提供同步操作。

## 查询流程

1. 确认用户希望查找的类目名称、编号或父类目线索，及后续商品或店铺筛选用途。
2. 按 [接口说明](references/api.md) 准备查询，优先复用已有结果或缓存，再执行需要的检索。
3. 检查返回状态，核对匹配类目的名称和父类目关系；空结果时按接口说明解释数据范围。
4. 展示候选类目标识，供用户或后续筛选使用；需要继续查询时遵守执行方式中的调用约定。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/etsy_category_search.py '<JSON 参数>' [--inline]`。
- **调用约定**：同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，先核对关键词、参数和类目同步状态，避免连续更换关键词或自动翻页试探。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-etsy-category-search-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

不消耗算力 （限时）。本接口检索已同步的本地类目库。

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **明确查询对象**：结果来自已同步的类目库，不代表 Etsy 实时商品或店铺数据。
- **清晰展示类目**：用表格展示实际返回的类目名称、编号、层级和父类目关系；缺失字段不补造，也不将局部匹配结果拼成完整类目树。
- **区分父类目关系**：规范主父类目与全部父类目是不同概念，具体字段约定见接口说明。
- **衔接下游筛选**：返回的 `id` 可供 Etsy 商品搜索或店铺侧的 `category` 等筛选使用，使用前核对目标工具的 schema。
