# 亚马逊商品详情查询

## 适用范围

### 适用

查看一个或多个 ASIN 的当前商品页面数据。当用户希望研究某个商品或比较竞品，且所需结论来自当前标题、价格、图片、五点描述、规格、评论或变体时，使用本技能，无需明确提及“商品详情”。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 查这个 ASIN 的详情 | 单品或批量详情查询。 |
| 提取五点描述、A+ 内容或商品描述 | Listing 内容提取。 |
| 提取新版标题之外的 Item Highlights | 有原始 HTML 时尝试补充解析。 |
| 比较这些竞品的价格和五点描述 | 按 ASIN 对比 Listing。 |
| 看这个商品德国站的价格 | 跨站点当前价格查询。 |
| 有多少评论、评分分布如何 | 展示评分、评论数和可用原始评论。 |
| 有哪些颜色、尺寸变体 | 变体结构查看。 |
| 获取主图，或查看尺寸、重量和成分 | 图片、规格与商品资料提取。 |
| 是否支持 Prime，有哪些徽章 | 资格与标识查看。 |

### 边界

关键词与搜索词分析、搜索结果排名、广告与 PPC、销量及收入估算、库存管理与 FBA 费用、历史价格追踪，以及需要额外 NLP 的评论情感分析，均应使用相应能力。

## 前置条件

**先确定查询对象与站点**：取得用户需要的 ASIN，核对目标站点和所需内容。参数格式、默认值、支持站点及使用限制见 `references/api.md`。

## 查询与 Item Highlights 提取流程

先核对查询范围并估算费用，提醒用户本服务按成功返回商品数动态计费，可能一次消耗大量算力，由用户决定是否继续。确认后按 `references/api.md` 准备参数，查询并保存完整响应，再按 ASIN 整理所需数据。

当用户需要 Item Highlights（新版标题之外的简短商品亮点）或检查 Listing 信息完整性，而结构化响应没有可确认的独立亮点字段时，按以下流程尝试补充：

1. **确认 HTML 入口**：调用 LinkFox 接口后，从脚本保存的完整响应中读取 `products[].rawHtmlFile`，并按同一对象的 `asin` 对应商品；批量请求不能只依赖 stdout 摘要或按结果顺序猜测。只有直接取得 SerpApi 原始响应时才读取 `search_metadata.raw_html_file`，也可使用用户提供的原始 HTML 文件或链接。`products[].pageFileUrl` 是处理后的商品 JSON，不是原始 HTML。
2. **读取原始 HTML**：有可用入口时，用 HTTP/文件读取工具获取内容，遵守 `references/api.md` 中的原始 HTML 读取约定。
3. **定位并提取**：先搜索 `Item Highlights`、`itemHighlights`、`item_highlights` 等线索，再结合当前商品标题区域的 DOM 或明确标注的数据字段确认对应内容；不能仅凭标签文字命中就认定是新版亮点。提取正文、解码 HTML 实体并整理空白，不自行生成或改写文案。
4. **区分其他内容**：只提取当前 ASIN 独立于 `title` 的简短商品亮点，不把 `aboutItem` / About This Item 五点描述、规格表、完整描述、评论摘要或推荐商品内容当作 Item Highlights。
5. **展示提取结果**：与 `title` 分开展示，注明“从原始 HTML 提取”，保留可核验的元素位置或简短原文片段；这是 AI 补充解析的结果，不宣称接口已原生返回该字段，也不改写原始接口响应。
6. **明确失败边界**：没有 HTML 入口时提示“缺少原始 HTML，无法解析”，可请用户提供对应文件或链接；链接失效、读取失败、遇到验证页或无法确认内容时标注“未解析到 Item Highlights”，保留正常商品数据。不能据此判断卖家未填写，也不得自动重调付费详情接口或切换服务商。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/amazon_product_detail.py '<JSON 参数>' [--inline]`。
- **成本约束**：本工具按成功返回商品数 × 15 计算算力消耗。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改邮编连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-amazon-product-detail-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

按动态规则计费：消耗算力 = 成功返回商品数 × 15。

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **理解数据来源**：本技能通过亚马逊前台页面模拟取得当前快照，可涵盖标题、主图与附图、About This Item、规格、A+ 内容、价格、评分分布和变体，以及按需取得的经常一起购买、相关商品和原始评论。以实际返回内容为准，不补造缺失字段。
- **清晰展示**：规格和价格比较用表格，五点描述用列表；多商品结果分别标注 ASIN 与标题。
- **处理图片**：将商品图、缩略图等可用 URL 展示为可点击链接或适当嵌入的图片。
- **标明价格**：价格附币种或货币符号；有折扣时同时展示现价和原价。
- **展示评分**：有星级分布时，与总评分和评论数一并展示；若返回占比则展示五星至一星占比，字段为计数时注明计数，换算占比需说明依据，不将计数直接加百分号。
- **展示变体**：按颜色、尺寸等维度分组，以紧凑表格呈现。
- **解释错误**：按 `references/api.md` 判断响应，说明原因并建议核对 ASIN 和站点；保留已取得的正常数据，后续请求遵守成本约束。
- **控制成本**：详情查询按商品计费，成本高于搜索类工具，仅批量查询用户确需的商品。

## 使用示例

### 查询单个或多个 ASIN

用户：查美国站 B072MQ5BRX 的商品详情。

```json
{"asins": "B072MQ5BRX"}
```

用户：获取 B072MQ5BRX 和 B08N5WRWNW 的详情。

```json
{"asins": "B072MQ5BRX,B08N5WRWNW"}
```

### 查询其他站点

用户：获取 B09V3KXJPB 在德国站的商品信息。

```json
{"asins": "B09V3KXJPB", "amazonDomain": "amazon.de"}
```

### 同时获取评论与经常一起购买的商品

用户：查询日本站 B08N5WRWNW，包含评论和经常一起购买的商品。

```json
{"asins": "B08N5WRWNW", "amazonDomain": "amazon.co.jp", "returnBoughtTogether": true, "returnAuthorsReviews": true}
```

### 比较竞品 Listing

用户：比较这三个 ASIN 的五点描述和价格。

```json
{"asins": "B072MQ5BRX,B08N5WRWNW,B09V3KXJPB"}
```

### 查看移动端页面数据

用户：查看英国站 B072MQ5BRX 的移动端商品页面数据。

```json
{"asins": "B072MQ5BRX", "amazonDomain": "amazon.co.uk", "device": "mobile"}
```
