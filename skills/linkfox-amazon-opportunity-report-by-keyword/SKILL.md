# 亚马逊关键词商业洞察报告

## 适用范围

### 适用

用户希望围绕一个亚马逊关键词获取多维市场全景、评估市场机会或了解竞争与消费者情况时，使用本技能。报告由 AI 基于查询时的亚马逊数据生成，用于选品和市场进入决策参考。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 帮我分析这个关键词的市场机会 | 关键词市场机会评估。 |
| 生成 XX 的商业洞察或选品报告 | 完整的六维洞察报告。 |
| XX 的竞争格局和价格分布如何 | 综合报告中的竞争及定价分析。 |
| XX 产品的消费者画像是什么 | 综合报告中的客户画像与行为洞察。 |
| 这个关键词值得进入吗 | 展示服务生成的市场进入评估，作为决策参考。 |

### 边界

“市场分析”或“产品调研”若指关键词市场的整体概览，使用本技能；若需要具体数据点，则使用对应专门工具：实时关键词排名交给 ABA 或 SIF，单品资料交给商品详情工具，历史价格交给 Keepa，指定 ASIN 的评论明细交给评论工具。广告或 PPC 策略不属于本技能范围。

## 前置条件

**先确定关键词及目标市场**：确认用户要研究的关键词和综合报告目标；支持范围与请求约定见 `references/api.md`。

## 生成与交付流程

1. 确认用户需要关键词层面的综合洞察，核对目标市场是否在接口支持范围内；不支持时说明覆盖范围，不替换为其他市场继续调用。
2. 提醒用户本次为动态计费，可能一次消耗大量算力；取得用户是否继续的决定后再执行请求。
3. 按 `references/api.md` 准备请求，优先复用同一会话、同一参数的已有结果或本地缓存，未命中时调用一次脚本。报告生成涉及 AI 分析，耗时可能长于简单查询，不因等待而重复提交。
4. 按接口参考判断网关与业务结果；成功时提取报告并按返回的 Markdown 结构展示。失败时依据返回消息解释原因，建议核对关键词或稍后再试；后续调用仍遵守成本约束。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/amazon_opportunity_report.py '<JSON 参数>' [--inline]`。
- **成本约束**：本工具按“算力消耗预估”中的动态公式计费。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改邮编连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-amazon-opportunity-report-by-keyword-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

按动态规则计费：消耗算力 = 输入消耗的算力 + 7.5 × 输出消耗的算力。

本服务按倍数动态计算，可能一次性消耗大量算力，必须提醒用户，由用户决定是否继续。

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **保持服务原有分析**：按 Markdown 原文展示 AI 生成的报告，不追加自己的主观商业建议；二次处理限制见 `references/api.md`。
- **说明快照性质**：报告反映生成时的数据，作为决策参考，不代表持续更新或实时监控。
- **六维内容**：按实际返回内容展示，不补造缺失章节或具体指标。

| 分析维度 | 内容含义 |
|----------|----------|
| 市场潜力 | 搜索量、需求趋势和增长机会。 |
| 产品特征 | 常见属性、材质和功能。 |
| 用户评论 | 情感、痛点和满意度驱动因素。 |
| 客户画像 | 买家人口特征、偏好和行为模式。 |
| 搜索趋势 | 关键词热度轨迹和季节性。 |
| 定价分析 | 价格分布与竞争定价格局。 |
