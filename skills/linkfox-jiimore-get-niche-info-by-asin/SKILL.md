# 极目亚马逊 ASIN 细分市场分析

## 适用范围

### 适用

用户已有具体商品，希望了解该商品所属市场的需求、竞争格局、品牌成熟度、价格结构和进入机会时，使用本技能。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 这个 ASIN 属于哪些细分市场 | 商品与细分市场的关联查询。 |
| 分析这个 ASIN 所在市场 | 查看需求、销售、价格与竞争指标。 |
| 这个产品的市场垄断程度或品牌集中度如何 | 查看品牌数量及头部品牌、商品的点击份额。 |
| 找出这个 ASIN 相关的低竞争市场 | 根据用户给出的条件筛选相关市场。 |
| 这些市场的新品成功率怎么样 | 查看新品发布数量、成功数量和成功率。 |
| 展示这个商品所在市场的数据 | 列举相关市场及核心指标。 |
| 这个 ASIN 所在市场的 CPC 或广告成本是多少 | 展示广告成本和竞争指标。 |

### 边界

关键词驱动的细分市场发现使用对应关键词技能；单品表现或销量估算、ABA 搜索词排名、广告管理、评论分析、Listing 优化和综合商业策略使用相应工具。本技能处理的是商品所属市场，不能将市场指标当作该商品自身表现。

## 前置条件

**先确定参考商品**：根据用户提供的 ASIN 开展市场研究，确认其关注的站点和筛选目标。完整参数及接口限制见 `references/api.md`。

## 查询与展示流程

1. 确定用户的参考商品、站点和筛选目标，按 `references/api.md` 构造请求。
2. 优先复用同一会话、同一参数组合的已有结果或本地缓存；没有可用结果时再查询。
3. 检查响应并读取已保存数据，按用户关注的维度展示市场指标；解释失败或空结果的原因。
4. 失败或空结果时，不得自动更换 ASIN、国家或放宽筛选连续试探。可以建议核对商品及站点或放宽范围；后续检索先说明额外算力消耗，再按用户决定执行。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/jiimore_get_niche_info_by_asin.py '<JSON 参数>' [--inline]`。
- **成本约束**：接口调用消耗 9 算力/次。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换 ASIN、国家或放宽筛选连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-jiimore-get-niche-info-by-asin-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

9 算力 / 次

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **细分市场含义**：Niche 是亚马逊上共享关键词主题的一组商品。本技能根据参考商品找到关联市场，并展示搜索、销售、点击、品牌、新品、广告成本和综合需求等维度。
- **需求得分**：`demand` 是市场综合机会得分，值越高表示需求潜力越高；不能据此保证商品开发结果。
- **清晰展示数据**：使用表格，主要列始终包括市场标题、需求得分、周搜索量、周销量、品牌数和前五品牌点击份额。
- **百分比展示**：将返回的小数比例转换为百分比，例如 `0.35` 展示为 `35%`；请求中的数值约定见接口文档。
- **中英标题并列**：用户偏好中文且存在 `translationZh` 时，与原始 `nicheTitle` 一同展示。
- **完整展示 CPC**：存在 CPC 数据时同时展示低、中、高三档，帮助用户了解广告成本区间。
- **解释空结果和错误**：按 `references/api.md` 判断原因。无匹配市场时说明筛选结果为空，建议核对 ASIN 或放宽范围；错误时依据响应消息解释，不擅自追加查询。
- **客观呈现**：不附加用户未要求的商业建议；只有用户明确要求时才提供解释或分析。

## 使用示例

### 查看参考商品在美国站的相关市场

```json
{"asin": "B0D9NWVC6Z", "countryCode": "US", "count": 10}
```

### 筛选品牌分散、竞争较低的市场

```json
{"asin": "B0D9NWVC6Z", "countryCode": "US", "count": 20, "top5BrandsClickShareMax": 0.5, "brandCountMin": 20}
```

### 筛选需求和转化表现较高的市场

```json
{"asin": "B0D9NWVC6Z", "countryCode": "US", "searchVolumeT7Min": 10000, "clickConversionRateT7Min": 0.1}
```

### 查看新品成功率较高、退货率较低的市场

```json
{"asin": "B0D9NWVC6Z", "countryCode": "US", "launchRateT180Min": 0.2, "returnRateT360Max": 0.05}
```

### 查看日本站相关市场

```json
{"asin": "B0D9NWVC6Z", "countryCode": "JP", "count": 10}
```

### 查看指定价格区间且广告占比较低的市场

```json
{"asin": "B0D9NWVC6Z", "countryCode": "US", "avgPriceMin": 20, "avgPriceMax": 50, "sponsoredProductsPercentageMax": 0.3}
```
