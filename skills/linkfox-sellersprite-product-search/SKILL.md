# 卖家精灵商品搜索

## 适用范围

### 适用

从亚马逊商品维度进行选品调研与市场分析。用户希望按销量、价格、排名、评分等商品属性筛选或对比产品时使用，无需明确提及卖家精灵。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 找某个类目销量高的商品 | 细分市场商品搜索。 |
| 看看竞争较小或值得开发的新品 | 结合上架时间、评分数和销售额筛选。 |
| 哪些商品毛利率高 | 盈利空间筛选。 |
| 找销量上涨、增长快的商品 | 销量增长趋势筛选。 |
| 中国卖家在卖什么畅销商品 | 卖家来源与竞争格局分析。 |
| 最近上架但卖得不错的商品 | 新品跟踪。 |
| 找评分较低但销量好的商品 | 产品改良机会筛选。 |
| 这个类目与去年相比如何 | 月度快照和季节性同比研究。 |
| 找低于 30 美元、销量超过 1000 的 FBA 商品 | 多条件组合筛选。 |
| 这个类目的 Best Seller 商品有哪些 | 按商品标识发现候选。 |

### 边界

关键词搜索量、搜索词排名、点击和转化份额属于 ABA 关键词数据分析；广告/PPC、评论正文、Listing 文案优化、供应商与制造成本、物流和库存规划使用对应能力。泛称“选品”或“市场分析”时，按用户实际需要的是商品筛选还是关键词指标判断范围。

## 前置条件

确定目标站点、商品范围及筛选目的；调用前按 `references/api.md` 检查参数与使用限制，缺少必要条件时先向用户补齐。

## 商品筛选流程

1. 将用户条件整理为商品查询：确定站点、关键词或类目、筛选指标和数据时期；将关键词翻译为目标站点语言并说明译词。
2. 根据调研目的选择筛选与排序：高销量、低竞争新品、产品改良、高毛利、卖家竞争、商品标识或增长趋势。季节性和同比研究使用相同口径的历史快照，具体约定见 `references/api.md`。
3. 先复用同参数缓存或已保存结果，再按执行方式发起必要查询。失败或空结果时依据消息解释原因；需要调整条件或继续查询时遵守成本约束。
4. 先读摘要，按需提取落盘字段，输出商品对比表，注明数据时期、总匹配数、本次返回范围及分页限制。历史对比不得混淆实时数据和快照。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/sellersprite_product_search.py '<JSON 参数>' [--inline]`。
- **成本约束**：本工具每次接口调用消耗 15 算力。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改邮编连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-sellersprite-product-search-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

15 算力 / 次

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **理解 BSR**：数值越小，类目内销售排名越好；BSR 为 1 表示类目首位。“排名改善”表示数值下降，“排名下滑”表示数值上升。
- **理解数据时期**：近 30 天数据与历史月度快照是不同口径；历史快照适用于季节性、同比和环比分析，展示时明确标注月份，例如“2024 年 12 月快照”。
- **理解关键词匹配**：词组匹配要求标题包含关键词词组，模糊匹配覆盖相关词，精准匹配要求严格字符串匹配；编码及默认值见接口定义。
- **清晰展示数据**：优先用表格展示 ASIN、标题、价格、月销量、月销售额、BSR、评分、评分数、毛利率和配送方式；只展示实际返回的指标。
- **说明毛利含义**：毛利率是百分比，是根据价格扣除 FBA 运费及估算成本得到的估值，不能当成实际经营利润。评分较低但销量好的商品可用于识别改良机会，不能据此推断具体差评原因。
- **说明分页情况**：总匹配数超过本页数量时说明尚有数据，后续查询须遵守接口定义中的可查询范围；超过范围时建议收紧筛选，不承诺能取全量结果。
- **解释错误原因**：按接口响应码规则判断响应，结合 `errmsg` 或业务 `message` 解释失败原因，给出调整条件的建议；不因建议而自动追加收费查询。
- **脚本运行约定**：脚本选项、缓存路径与有效期、会话追踪头、认证变量兼容及落盘约定统一见 `references/api.md`；缓存命中仍保存完整响应。

## 使用示例

### 细分市场高销量商品：美国站瑜伽垫，月销量至少 500 件

```json
{
  "keyword": "yoga mat",
  "marketplace": "US",
  "minUnits": 500,
  "order": {"field": "total_units", "desc": "true"}
}
```

### 低竞争新品机会：近 6 个月上架、评分数不超过 50、月销售额至少 5000

```json
{
  "keyword": "desk organizer",
  "marketplace": "US",
  "listedWithinLastMonths": 6,
  "maxRatings": 50,
  "minRevenue": 5000,
  "order": {"field": "total_units", "desc": "true"}
}
```

### 产品改良机会：评分 3.8–4.3、月销量至少 300 件

```json
{
  "keyword": "phone case",
  "marketplace": "US",
  "minRating": 3.8,
  "maxRating": 4.3,
  "minUnits": 300,
  "order": {"field": "total_units", "desc": "true"}
}
```

### 高毛利筛选：毛利率至少 40%、价格 15–50、月销量至少 100 件

```json
{
  "marketplace": "US",
  "minProfit": 40,
  "minPrice": 15,
  "maxPrice": 50,
  "minUnits": 100,
  "order": {"field": "profit", "desc": "true"}
}
```

### 季节性同比分析：查询 2024 年 12 月圣诞灯历史快照

```json
{
  "keyword": "christmas lights",
  "marketplace": "US",
  "dataSnapshotMonth": "202412",
  "minUnits": 200,
  "order": {"field": "total_units", "desc": "true"}
}
```

### 中国卖家竞争格局：FBA 配送、月销量至少 200 件

```json
{
  "keyword": "bluetooth speaker",
  "marketplace": "US",
  "sellerNation": "CN",
  "fulfillment": "FBA",
  "minUnits": 200,
  "order": {"field": "total_units", "desc": "true"}
}
```

### Best Seller 标识商品：按月销量降序

```json
{
  "keyword": "water bottle",
  "marketplace": "US",
  "badgeBestSeller": "Y",
  "order": {"field": "total_units", "desc": "true"}
}
```

### 快速增长商品：月销量增长率至少 50%

```json
{
  "keyword": "standing desk",
  "marketplace": "US",
  "minUnitsGrowthRate": 50,
  "order": {"field": "total_units_growth", "desc": "true"}
}
```
