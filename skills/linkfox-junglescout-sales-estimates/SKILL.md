# Jungle Scout ASIN 销售估算

## 适用范围

### 适用

查看指定亚马逊 ASIN 在一段时间内的每日预估售出件数与最近已知价格，用于监控竞品、验证选品需求、观察旺淡季、评估价格与销量变化关系或跟踪新品。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 这个 ASIN 一天能卖多少 | 查询近期日销量估算。 |
| 竞品最近卖得怎么样 | 未指定具体区间时，监控截至昨天的近 30 天销量及日均销量。 |
| 这个产品有没有季节性 | 查看全年走势，识别旺淡季规律。 |
| 帮我看看这个品的销量趋势 | 展示指定时间范围内的每日变化。 |
| Q4 旺季销量如何 | 查询季度数据，按需与其他季度比较。 |
| 这个产品值不值得做 | 用历史销量估算验证需求，作为选品判断的一项依据。 |
| 大促期间卖了多少 | 查看活动期间的每日估算与汇总。 |

关键词搜索量、BSR 排名历史、类目整体销量或市场规模、非亚马逊平台及实时销量查询不属于本技能范围。

## 前置条件

确定待查 ASIN 与目标时间范围；站点及自然语言日期的处理方式见 `references/api.md`。缺少 ASIN 或无法确定时间范围时，先补齐信息。

## 查询流程

1. 读取 `references/api.md`，将用户提供的站点、ASIN 和时间表达转换为查询条件，核对请求约束。
2. 根据用户目标安排查询：近期竞品监控查询近期区间，季节性研究查询全年，新品跟踪覆盖上架后的目标时段，大促分析覆盖活动区间。季度对比按季度分别查询；多商品对比按目标分别查询，提前说明调用次数与算力消耗。
3. 优先复用同一参数组合的已有结果或缓存；需要新数据时运行推荐脚本，按输出摘要定位保存的完整响应。
4. 按接口文档判断响应；保留父体、变体和独立商品关系，再读取每日估算。空结果或失败时解释原因，后续请求遵守成本约束。
5. 展示日销量与价格走势、数据表和汇总指标，并说明趋势方向、峰谷日期及数据口径。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/junglescout_sales_estimates.py '<JSON 参数>' [--inline]`。
- **成本约束**：本工具每次调用消耗 64 算力。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改邮编连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-junglescout-sales-estimates-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

64 算力 / 次

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **说明数据口径**：每日销量为 Jungle Scout 的估算值，并非卖家后台实测出单量；用于需求验证、季节性观察和竞品比较时均应标明这一点。
- **折线图优先**：横轴为日期，纵轴为预估日销量；需要对照价格时，可叠加第二 Y 轴。
- **表格辅助**：同时提供日期、预估销量、最近已知价格，便于精确查阅。价格币种与字段含义见 `references/api.md`。
- **汇总统计**：给出区间预估总销量、日均销量和粗略预估总收入（总销量 × 均价），说明均价口径与有效数据天数；缺失数据不补零，不把最近已知价格视为实际成交价格。
- **趋势总结**：概括上升、下降、平稳或周期性波动，标注销量峰值和谷值日期。价格与销量的同步变化可辅助定价分析，不能直接证明因果关系。
- **保留商品关系**：区分父体、变体和独立商品；展示返回的父子关系，避免重复汇总父体及其变体数据。
- **解释错误原因**：依据接口文档和原始错误说明提出调整建议；失败或空结果不得自动改条件反复查询。
