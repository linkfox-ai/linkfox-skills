# `GET_V1_SELLER_PERFORMANCE_REPORT`

> **分类**：11. 绩效报告  
> **说明**：卖家绩效 v1  
> **可用范围**：仅卖家

## 官方说明（Report type values）

以下内容整理自官方 [Report type values](https://developer-docs.amazon.com/sp-api/docs/report-type-values) 子页 [绩效报告](https://developer-docs.amazon.com/sp-api/docs/report-type-values-performance#xml-customer-metrics-report)（章节：**XML Customer Metrics Report**）。**与专页其它段落冲突时以官方英文文档为准。**

- **受限报告**：按当前小节文本为否（仍以官方为准）
- **角色**：[Selling Partner Insights](https://developer-docs.amazon.com/sp-api/docs/roles-in-the-selling-partner-api#selling-partner-insights)
- **可用范围**：卖家
- **按需/计划**：本报告仅可按需请求。
- **输出格式**：XML
- **要点**：包含 Seller Central 仪表板选定的逐项绩效指标。

- **官方直达**：<https://developer-docs.amazon.com/sp-api/docs/report-type-values-performance#xml-customer-metrics-report>

- [https://developer-docs.amazon.com/sp-api/docs/report-type-values](https://developer-docs.amazon.com/sp-api/docs/report-type-values)

## CreateReport 请求体（最小常用）

多数此类报告可按下述最小结构创建（是否支持 `dataStartTime`/`dataEndTime` 及格式以官方文档为准）：

```json
{
  "reportType": "GET_V1_SELLER_PERFORMANCE_REPORT",
  "marketplaceIds": ["ATVPDKIKX0DER"]
}
```

支持日期范围时，可补充例如：

```json
{
  "reportType": "GET_V1_SELLER_PERFORMANCE_REPORT",
  "marketplaceIds": ["ATVPDKIKX0DER"],
  "dataStartTime": "2024-01-01T00:00:00Z",
  "dataEndTime": "2024-01-31T23:59:59Z"
}
```

若官方要求 **`reportOptions`** 或其它字段，必须一并传入（见 Report type values）。
