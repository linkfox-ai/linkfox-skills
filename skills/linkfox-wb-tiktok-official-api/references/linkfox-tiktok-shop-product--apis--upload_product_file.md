# Upload Product File

## MCP 调用

| 项 | 固定值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `tiktokShop/developerProxy` |
| `arguments` | 直接使用本 reference 的请求对象；不得额外包裹 `body`、`data` 或另一层 `arguments` |
| 响应字段来源 | `skills/linkfox-tiktok-shop-product/references/apis/upload_product_file.md`；只按其响应契约核对字段表 |

```json
{
  "toolName": "tiktokShop/developerProxy",
  "arguments": {"appType": "erp", "openId": "<openId>", "path": "product/202309/files/upload", "method": "POST"}
}
```

- `toolName` 精确匹配且区分大小写；MCP 缺失时停止，禁止 HTTP fallback。
- WorkBuddy 自动注入 MCP Authorization；不得传 LinkFox `headers`、API Key、`token`、JWT 或手机号。
- 收费失败、空结果或结果不理想时不自动重试；相同 `toolName + arguments` 在同一任务内不重复调用。
- 先处理 MCP/schema/`isError`；text JSON 只解析一次；再检查下游错误字段和业务结果。

> 官方文档：https://partner.tiktokshop.com/docv2/page/upload-product-file-202309

## LinkFox 转发映射（本 skill）

| 项 | 值 |
|----|----|
| 具名 api | `upload_product_file` |
| 本地辅助 | 无；当前 multipart 文件上传不支持通过 `proxy_call` 执行 |
| 网关 | `POST tiktokShop/developerProxy` |
| appType | **`erp`（固定）** |
| 上游 path | `product/202309/files/upload` |
| method | `POST` |
| shop_cipher | 是（Query `shop_cipher`；必须显式传入；可先调用本域 Get Authorized Shops 取得） |
| 令牌 | 网关按 `openId` + `appType=erp` 从库取 token（`ttsAccessToken` 已废弃忽略；401/过期时自动刷新并重试一次） |

## 官方接口原文（TikTok Shop Partner Center）

# Path: /product/202309/files/upload
# Method: [POST]
# Function Description
Upload non-image files, such as PDF or video to TikTok Shop.
Use this API when you need to add videos to your product to improve the shopping experience, or submit certifications or reports to meet TikTok Shop requirements for listing restricted products.
**Note**: You must store the response body to retrieve the ID or URL required to associate the file with a product during product creation or editing.

---
