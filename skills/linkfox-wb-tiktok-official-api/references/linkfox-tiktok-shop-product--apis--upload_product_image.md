# Upload Product Image

## MCP 调用

| 项 | 固定值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `tiktokShop/developerProxy` |
| `arguments` | 直接使用本 reference 的请求对象；不得额外包裹 `body`、`data` 或另一层 `arguments` |
| 响应字段来源 | `skills/linkfox-tiktok-shop-product/references/apis/upload_product_image.md`；只按其响应契约核对字段表 |

```json
{
  "toolName": "tiktokShop/developerProxy",
  "arguments": {"appType": "erp", "openId": "<openId>", "path": "product/202309/images/upload", "method": "POST"}
}
```

- `toolName` 精确匹配且区分大小写；MCP 缺失时停止，禁止 HTTP fallback。
- WorkBuddy 自动注入 MCP Authorization；不得传 LinkFox `headers`、API Key、`token`、JWT 或手机号。
- 收费失败、空结果或结果不理想时不自动重试；相同 `toolName + arguments` 在同一任务内不重复调用。
- 先处理 MCP/schema/`isError`；text JSON 只解析一次；再检查下游错误字段和业务结果。

> 官方文档：https://partner.tiktokshop.com/docv2/page/upload-product-image-202309

## LinkFox 转发映射（本 skill）

| 项 | 值 |
|----|----|
| 具名 api | `upload_product_image` |
| 本地辅助 | `scripts/upload_product_image.py`（仅生成 Base64 `arguments`，不联网） |
| 网关 | `POST tiktokShop/developerProxy` |
| appType | **`erp`（固定）** |
| 上游 path | `product/202309/images/upload` |
| method | `POST` |
| shop_cipher | 是（Query `shop_cipher`；必须显式传入；可先调用本域 Get Authorized Shops 取得） |
| 令牌 | 网关按 `openId` + `appType=erp` 从库取 token（`ttsAccessToken` 已废弃忽略；401/过期时自动刷新并重试一次） |

### developerProxy 示例

```json
{
  "appType": "erp",
  "openId": "7010...",
  "path": "product/202309/images/upload",
  "method": "POST",
  "queryString": "shop_cipher=GCP_...",
  "contentType": "image/png",
  "multipartFileName": "product.png",
  "multipartFileBase64": "iVBORw0KGgoAAA...",
  "useCase": "MAIN_IMAGE"
}
```

### 本地参数构造

> 需要读取本地图片时，运行 `scripts/upload_product_image.py` 生成 `arguments`，再使用本页 `MCP 调用` 的完整 `proxy_call` 参数结构。

脚本也接受调用方已经编码好的 `multipartFileBase64`，此时必须同时传
`multipartFileName` 和正确的图片 MIME `contentType`。Base64 必须仅包含文件原始
字节的编码，不要带 `data:image/png;base64,` 前缀。LinkFox 网关负责解码，并构造
TikTok 官方接口要求的 `multipart/form-data`：文件 part 名为 `data`，`useCase`
转换为表单字段 `use_case`。成功后保存响应中的 `data.uri`，供创建/编辑商品引用。

## 官方接口原文（TikTok Shop Partner Center）

# Path: /product/202309/images/upload
# Method: [POST]
# Function Description
Upload local images to TikTok Shop for use as product images, variant images, size charts, certification images and so on.
**Note**:

* All images used in TikTok Shop products must be uploaded through this API. You will not be able to use any image URLs that are not hosted by TikTok Shop.
* You must store the response body to retrieve the ID or URL required to associate the image with a product during product creation or editing.

* DESCRIPTION_IMAGE: An image used within the product description.
* CERTIFICATION_IMAGE: An image to provide supporting information to meet TikTok Shop requirements for listing restricted products (e.g., images of certifications, product packaging, labeling).

**Note**: Images for use cases `MAIN_IMAGE` and `ATTRIBUTE_IMAGE` that do not fit within the 3:4 to 4:3 aspect ratio range will be automatically converted to 1:1. |
