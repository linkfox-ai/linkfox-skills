# Update Inventory

## MCP 调用

| 项 | 固定值 |
|---|---|
| MCP server | `LinkFox` |
| 唯一工具 | `proxy_call` |
| `toolName` | `tiktokShop/developerProxy` |
| `arguments` | 直接使用本 reference 的请求对象；不得额外包裹 `body`、`data` 或另一层 `arguments` |
| 响应字段来源 | `skills/linkfox-tiktok-shop-product/references/apis/update_inventory.md`；只按其响应契约核对字段表 |

```json
{
  "toolName": "tiktokShop/developerProxy",
  "arguments": {"appType": "erp", "openId": "<openId>", "path": "product/202309/products/{product_id}/inventory/update", "method": "POST"}
}
```

- `toolName` 精确匹配且区分大小写；MCP 缺失时停止，禁止 HTTP fallback。
- WorkBuddy 自动注入 MCP Authorization；不得传 LinkFox `headers`、API Key、`token`、JWT 或手机号。
- 收费失败、空结果或结果不理想时不自动重试；相同 `toolName + arguments` 在同一任务内不重复调用。
- 先处理 MCP/schema/`isError`；text JSON 只解析一次；再检查下游错误字段和业务结果。

> 官方文档：https://partner.tiktokshop.com/docv2/page/update-inventory-202309

## 官方接口原文（TikTok Shop Partner Center）

# Path: /product/202309/products/{product_id}/inventory/update
# Method: [POST]
# Function Description
Update the inventory quantity of SKUs belonging to a product. The SKU ID must belong to a product that is **not** in `FREEZE` or `DELETED` status.
