# Shopify 商品查询

## 适用范围

### 适用

查询和筛选 Shopify 独立站商品，比较候选的销量、销售额、广告数量、货源情况和竞争度。
用户希望在 Shopify 上搜商品、查看周销量或筛选适合研究的商品时，使用本技能。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 帮我找 Shopify 上的手机壳 | 关键词商品搜索。 |
| 看这个 Shopify 商品或店铺链接 | 按 URL 查询匹配商品。 |
| 找有 Facebook 广告且有货源的商品 | 广告与货源条件筛选。 |
| 看美国发货、近期上架的畅销品 | 发货国家、上架时间与销量筛选。 |
| 比较这些商品的销量和竞争度 | 展示周销量、周销售额和在售店铺数量。 |

## 前置条件

**先确定查询目标**：按用户提供的关键词、URL 或筛选条件整理一次查询；参数、排序约定和脚本环境配置见 [references/api.md](references/api.md)。

## 查询流程

1. 根据用户目标整理关键词、商品或店铺 URL 及筛选条件，按接口文档核对区间、排序和分页约定。
2. 按“算力消耗预估”预估本次查询的算力消耗并向用户说明，由用户决定是否继续。
3. 执行已确定的一次查询，先查看摘要，再从保存的完整响应中提取所需字段。
4. 展示商品与查询覆盖范围，说明是否还有更多候选；需要扩大范围或翻页时，遵守成本约束。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/shopify_product_query.py '<JSON 参数>' [--inline]`。
- **成本约束**：本工具会消耗算力。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改筛选条件连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-shopify-product-query-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

消耗算力 = 返回的商品数 × 1.8，按本页实际返回条数计费。翻到下一页相当于再发一次请求，再按该页返回条数计费。

本服务按动态倍数计费，可能一次性消耗大量算力，必须提醒用户，由用户决定是否继续。

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **解释指标**：竞争度是销售该商品的店铺数量；周销量、周销售额和周销售额增长率是不同指标，不混用。
- **区分记录数与总数**：分别展示本页商品数和符合条件的商品总数，不能将本页数量当作市场规模。
- **清晰展示候选**：用表格列出可用的商品标题、链接、价格区间、周销量、周销售额、增长率、竞争度、广告数量、发货国家和上下架状态；缺失数据标为未返回。
- **保留数据含义**：上游可能将周销量返回为字符串，保留其原始含义；展示百分比时以返回值和字段说明为准，不自行补造数据。
- **解释空结果与错误**：无数据时网关也可能返回错误；结合响应消息说明原因，后续查询遵守成本约束。接口判断规则见 [references/api.md](references/api.md)。

## 使用示例

### 按关键词查询候选

用户：帮我找美国发货的 Shopify 手机壳，看看销量和竞争度。

确定关键词和发货范围，说明预计消耗后查询，展示候选商品及周销量、销售额与在售店铺数量。

### 按广告和货源筛选

用户：找有 Facebook 广告、能找到货源的 Shopify 商品。

按用户的商品方向结合广告和货源条件查询，展示匹配结果与本次覆盖范围；不将有广告或有货源直接解释为值得开发。
