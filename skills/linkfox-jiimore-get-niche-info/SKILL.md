# 极目亚马逊细分市场洞察

## 适用范围

### 适用

查询已知亚马逊细分市场的市场级情报。用户希望了解某个细分市场的需求、竞争、价格、上新成功率、买家反馈或断货情况时使用，无需明确提及极目。

**场景速查**

| 用户表达 | 查询场景 |
|----------|----------|
| 查这个细分市场的信息 | 市场概览与需求评分。 |
| 这个市场竞争激烈吗，品牌集中度如何 | 商品与品牌点击份额及竞争趋势。 |
| 这个市场的平均价格、利润怎么样 | 价格区间、盈利比例、退货率与 ACOS。 |
| 看搜索量、需求增长和转化趋势 | 周度与季度搜索、点击、转化和销量。 |
| 新品多不多，上架成功率如何 | 新品数量、成功上架数量和成功率。 |
| 看买家反馈或评分变化 | 评论评分、评论数量、正负面见解与星级影响。 |
| 缺货严重吗，卖家成熟度如何 | 库存健康、品牌和销售伙伴年龄。 |
| 这个细分市场是否值得进入 | 根据用户要求综合评估已有市场数据。 |

### 边界

关键词或类目找市场、单个 ASIN 分析、ABA 搜索词数据、广告活动管理、PPC 优化、Listing 文案和评论管理不属于本技能范围。

## 前置条件

**先确定细分市场编号**：由用户提供或从已有上游数据中确认目标 `nicheId`，不要编造编号。请求字段与站点约定见 `references/api.md`。

## 查询与分析流程

1. 确认目标细分市场与站点，按 `references/api.md` 核对所需信息；信息不足时先补齐。
2. 按用户查询范围发起查询。需要比较多个市场时逐个取得数据，并评估调用次数和额外消耗。
3. 先检查响应与摘要，按需从已保存的 JSON 提取指标；失败或空结果时解释返回原因，建议核对编号或站点，后续查询遵守成本约束。
4. 按市场概览、价格与盈利、搜索与需求、竞争、上新、评论、库存与运营分组整理，并依据下方展示建议呈现。

## 执行方式

- **直接调用接口**：接口端点、完整参数、响应和错误码见 `references/api.md`。
- **脚本调用（推荐）**：`python scripts/jiimore_get_niche_info.py '<JSON 参数>' [--inline]`。
- **成本约束**：本工具会消耗算力。同一会话、同一参数组合默认只调用一次，脚本提供 24 小时本地缓存。失败或空结果时，不得自动更换关键词、翻页或修改邮编连续试探；需要继续检索时，先向用户说明额外消耗。

### 输出策略

- 始终保存完整响应，目标路径为 `<cwd>/linkfox/<YYYY-MM-DD>/<session>/data/linkfox-jiimore-get-niche-info-<timestamp>.json`。`<cwd>` 为脚本运行时的工作目录，`<session>` 优先取环境变量 `SESSION_ID`，用于聚合同一任务的数据。禁止写入 `/tmp`，当前目录不可写时应报错。
- 响应体不超过 8 KB：保存后，将完整 JSON 打印到标准输出。
- 响应体超过 8 KB：保存后，标准输出仅展示摘要，包括顶层字段、常见计数（如 `total`、`costToken`）、最大列表字段的长度和前 3 条样本。
- 添加 `--inline` 可强制全量打印到标准输出，同时仍保存文件。

先通过摘要判断数据是否足够。需要具体字段时，优先使用 `jq` 或 `ConvertFrom-Json` 从保存的 JSON 文件按需提取，避免将整份响应载入上下文。

## 执行规则

### 算力消耗预估

9 算力 / 次

**声明**：算力消耗以实际扣除为准；如因需要调整算力消耗标准，恕不另行通知。最终解释权归 LinkFox 官方所有。

用户会因算力消耗而支付费用。需要高频调用或用户对消耗量预期不足时，提醒用户，并由用户决定是否继续。

### 解决认证和算力问题

出现以下情况时，按 `references/onboarding.md` 的指引处理：

- 未配置接口密钥：`LINKFOX_AGENT_API_KEY` 和 `LINKFOXAGENT_API_KEY` 均为空。
- 响应状态码为 `401` 或 `402`。
- 响应提示算力或余额不足、计费不足、配额超限、套餐到期或需要充值。英文错误消息也按其含义判断。

### 约束与建议

- **理解细分市场**：极目的细分市场是亚马逊上的精细商品分组，`nicheId` 是该分组的唯一标识。返回市场级指标，不能将其当成某个 ASIN 的单品表现。
- **清晰展示数据**：使用表格或分组展示实际返回的指标；除非用户明确要求，不附加主观经营建议。
- **市场概览**：展示英文标题及可用的中文译名、需求评分、商品数、品牌数和销售伙伴数；有 `referenceAsinImageUrl` 时展示或链接参考图片。
- **价格与盈利**：展示均价、最低价、最高价、利润率大于 50% 的商品比例、盈亏平衡自然占比、退货率和 ACOS。
- **搜索与需求**：展示周度与季度搜索量、增长率、搜索转化率、点击量、点击转化率和销量。
- **竞争与卖家成熟度**：展示前 5 / 前 20 商品和品牌的点击份额、品牌数、销售伙伴数、品牌与销售伙伴年龄、平均 BestSeller 排名，以及商品推广占比。
- **上新活动**：展示不同时间窗口的新上架数量、成功上架数量和半年上架成功率。
- **评论与客户见解**：展示平均评分、平均评论数及变化；正面和负面评论见解分别以要点列出，并展示可用的产品星级影响。
- **库存与运营**：展示平均缺货率及 Prime 商品比例变化。
- **并列比较趋势**：存在当前、90 天前和 360 天前指标时并列展示；区分统计窗口与快照时间，避免混合周度、季度、半年或 360 天统计口径。
- **百分比格式**：份额和比率用百分比展示，例如 `0.35` 显示为 `35.0%`。
- **解释错误原因**：依据实际响应说明原因，认证与算力问题按上方指引处理；响应判定和接口使用限制见 `references/api.md`。
